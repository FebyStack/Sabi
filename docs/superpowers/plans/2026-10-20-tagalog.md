# Tagalog / Taglish Pipeline Implementation Plan (3c)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Tagalog or Taglish clip goes through the whole Sabi pipeline as well as an English one: every spoken word gets a timing, filler cuts know *ano / kasi / parang / 'yung / ganun / eh*, caption lines never strand *ng / sa / ang / mga*, emphasis lands on content words, and the Claude editor knows how to judge Taglish.

**Architecture:** The locked whisperX (3.8.6, `ai/transcription/uv.lock`) already ships a default `tl` aligner (`Khalsuu/filipino-wav2vec2-l-xls-r-300m-official`, 1.26 GB, Latin a–z vocabulary so English words in Taglish align too), so transcription needs robustness, not a new model: a segment that fails to align, or a language with no aligner at all, falls back to word timings spread over the segment by character length and the project gets a `timing_estimated` warning instead of losing words or failing. A spoken-language choice (web select, `run_job {language}`) fixes Taglish auto-detected as `en`. All Tagalog language rules live in one shared module (`shared/lang/tagalog.ts`) and are gated on the project's language, so English behaviour is unchanged. The LLM (Ollama) only gets a Tagalog note in its prompt plus a deterministic guard; the agent gets a skill section.

**Tech Stack:** existing — whisperX 3.8.6 / FastAPI sidecar (Python ≥ 3.11, `uv`), Express 5 + zod 4, vitest, React 19. New: `pytest` for the sidecar's pure timing module (run through `uv run --no-project --with pytest`, no venv needed).

**Spec:** `docs/spec.md` row 13 (Tagalog, added 2026-10-20); row 7 (whisperX + Ollama, **no Anthropic API**); row 10 (Claude edits through MCP, buttons stay on Ollama). Plan-2/3 interfaces this builds on: `shared/editing/cuts.ts` (`detectCuts`, `PAUSE_MIN_MS`, `PAUSE_PAD_MS`), `shared/captions/segment.ts` (`segmentCaptions`), `ai/llm/prompts.ts` (`PLAN_SYSTEM`), `backend/modules/editplan/planner.ts` (`planEdit`), `backend/shared/transcriber.ts` (`WhisperXTranscriber`, `FakeTranscriber`), `backend/mcp/tools.ts` (`run_job`), `.claude/skills/sabi-editor/SKILL.md`. Conventions: `PROJECT.md`.

**Interfaces:**
- `spread_words(text: str, start: float, end: float) -> list[dict]` — `text.split()` spread over `[start, end]` with durations proportional to character length, rounded to 3 decimals; returns `{"text", "start", "end"}` per word (no `score`); empty/blank text → `[]`.
- `words_from_segments(segments: list[dict]) -> tuple[list[dict], int]` — flattens whisperX segments (aligned or not) to sidecar words and returns `(words, estimated_count)`. A word with `start` and `end` passes through as `{"text": word.strip(), "start", "end", "score": w.get("score", 0)}`. A word without timing (whisperX leaves them out after a failed or partial alignment) is **never dropped**: each maximal run of untimed words is spread with `spread_words` over the span between its timed neighbours (segment `start`/`end` at the edges) and counted as estimated. A segment with no `"words"` key (no aligner) is one such run over the whole segment. Blank words are skipped.
- `server.py`: `aligner(language) -> tuple | None` replaces the `lru_cache` version: a dict cache filled only on success; `whisperx.load_align_model` raising (no default aligner for the language, or the model cannot be downloaded) logs a warning and returns `None` **without caching**, so the next request retries. `/transcribe` aligns only when `aligner(lang)` is not `None`, then always goes through `words_from_segments`, and returns `{"language": lang, "words": words, "estimated_words": n}`.
- `package.json`: `"test:py": "uv run --no-project --with pytest pytest -q ai/transcription"` (ephemeral pytest, system Python, no torch; pytest skips `.venv` by default) and `"verify": "npm run typecheck && npm run typecheck:server && npm run test && npm run test:py"`.

def test_spread_by_char_length():
    assert spread_words("ano ba yan", 10.0, 11.0) == [
        {"text": "ano", "start": 10.0, "end": 10.375}, {"text": "ba", "start": 10.375, "end": 10.625}, {"text": "yan", "start": 10.625, "end": 11.0}]

def test_blank_text_yields_nothing():
    assert spread_words("  ", 0.0, 1.0) == []
    assert words_from_segments([{"text": " ", "start": 0.0, "end": 1.0}]) == ([], 0)

def test_aligned_words_pass_through():
    seg = {"text": " Kumusta", "start": 0.1, "end": 0.5, "words": [{"word": " Kumusta", "start": 0.1, "end": 0.5, "score": 0.9}]}
    assert words_from_segments([seg]) == ([{"text": "Kumusta", "start": 0.1, "end": 0.5, "score": 0.9}], 0)

def test_untimed_run_is_spread_between_timed_neighbours():
    seg = {"text": "Ako ay si Ben", "start": 0.0, "end": 1.6, "words": [
        {"word": "Ako", "start": 0.0, "end": 0.3, "score": 0.8}, {"word": "ay"}, {"word": "si"}, {"word": "Ben", "start": 1.3, "end": 1.6, "score": 0.7}]}
    words, estimated = words_from_segments([seg])
    assert [w["text"] for w in words] == ["Ako", "ay", "si", "Ben"]
    assert (words[1], words[2]) == ({"text": "ay", "start": 0.3, "end": 0.8}, {"text": "si", "start": 0.8, "end": 1.3})
    assert estimated == 2

def test_segment_without_words_is_spread():
    words, estimated = words_from_segments([{"text": "Oo nga", "start": 2.0, "end": 3.0}])
    assert words == [{"text": "Oo", "start": 2.0, "end": 2.4}, {"text": "nga", "start": 2.4, "end": 3.0}]
    assert estimated == 2

**Files:**

**Interfaces:**
- `shared/lang/tagalog.ts`:
  - `isTagalog(language?: string | null): boolean` — `tl` or `fil`.
  - `normWord(text: string): string` — lower-case, letters only (`'yung` → `yung`, `Ano...` → `ano`).
  - `TL_HESITATION = new Set(["ano", "kasi", "parang", "yung", "ganun", "ganon", "eh", "like"])` — real words that are fillers only in hesitation position.
  - `TL_NO_STRAND = new Set(["ang", "ng", "nang", "sa", "mga", "at", "o", "kay", "ni", "si", "nina", "kung", "para", "pero", "dahil", "yung", "ay"])` — markers that must start a line with the word they govern.
  - `TL_FUNCTION_WORDS` = `TL_NO_STRAND` ∪ `TL_HESITATION` ∪ `{"na", "po", "ho", "ba", "pa", "din", "rin", "lang", "naman", "daw", "raw"}` — never emphasised.
- `cuts.ts`: `export const FILLER_GAP_MS = 250`; `detectCuts(words: Word[], durationMs: number, language?: string | null): Cut[]`. The English `FILLERS` set stays "always a filler". A **run** is a maximal sequence of consecutive words that are in `FILLERS` or (when `isTagalog(language)`) in `TL_HESITATION`. A run is an **island** when the gap before it (first word's `startMs` − previous word's `endMs`; ∞ at clip start) is `>= FILLER_GAP_MS` **and** either the gap after it is `>= FILLER_GAP_MS` (∞ at clip end) or the run's last word ends with `,` `.` or `…`/`...`; a run whose last word ends with `?` or `!` is never an island. `FILLERS` words are filler cuts always; `TL_HESITATION` words only inside an island. Cuts stay one per word (`reason: "filler"`, `text: w.text`, `shouldTrim: true`), numbered in time order with pauses as today; the "never cut the whole clip" guard uses the final filler set.
- `editplan/routes.ts`: `detectCuts(project.transcript!.words, durationMs, project.language)`.
