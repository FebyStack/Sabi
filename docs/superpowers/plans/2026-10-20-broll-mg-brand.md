**Goal:** After an edit plan exists, B-roll shots become beats filled with stock (Pexels) or generated (fal.ai) media; the editing agent (Claude over MCP) can also write motion-graphics B-roll as Remotion components and set a per-project brand kit that colours captions, motion graphics and the footage — all drawn by `CaptionVideo`, so `render_frame` = browser preview = MP4.

Every edit to them is a typed action in `ActionSchema`/`applyActions` (the web panel and the MCP `apply_actions` tool share that path); only the B-roll fetch (network) is a job. ## Global Constraints

- **No Anthropic API.** The only model calls are local Ollama through the plan-2 `Llm` port (beat labelling); the editing agent is the user's own Claude Code session over MCP. Provider keys `PEXELS_KEY` (free, 200 req/h) and `FAL_KEY` are optional at boot; a B-roll job that needs a missing one fails with `stock_unavailable` / `generator_unavailable` **before** changing the project.
- **Media source rule:** `mediaSource === "stock"` → Pexels only, never fal. `"generate"` → fal.ai images (`fal-ai/flux/schnell`, `costCents: 1`) and **at most one video beat per project** (`fal-ai/kling-video/v1.6/standard/image-to-video`, 5 s, `costCents: 25`); Pexels is the per-beat fallback when fal fails, never the reverse. Model ids are the exported constants `FAL_IMAGE_MODEL`, `FAL_VIDEO_MODEL` in `backend/shared/generator.ts`.
- **Beat rules** (`shared/editing/beats.ts`, committed in `acc2003`): one beat per `B-Roll` / `Talking Head & B-Roll` shot, start `shot.startMs + 300`, length `min(shotLength − 300, 5000)`, dropped under `1500`; `B-Roll` → `placement: "full"`, `Talking Head & B-Roll` → `"top"`; ids **0-based** `beat-<n>`. Overlay ids `ov-<n>`, motion-graphic ids `mg-<n>`: `n = 1 + max existing numeric suffix` (0 when none), so an id is never reused after a delete.
- **Caption-aware placement:** `top` overlays fill the band `top 6 %, height 49 %, left/right 4 %`, `borderRadius 16`, `cover`; `full` overlays cover the frame. Captions keep `template.position.y` (≥ 0.78) and always draw on top. A motion-graphic `box` whose `y + h > 0.72` is **allowed** but `inspect_project` flags it `⚠ overlaps captions`.
- **Layer order** in `CaptionVideo`: base media → B-roll overlays → brand tint (grade) → motion graphics → captions. The grade (CSS `filter` + a `soft-light` tint of `brand.palette.primary`) applies to the base media and B-roll overlays only — never to motion graphics or captions.
- **Transitions:** overlays `fade` = 10 frames in/out; images Ken Burns `scale 1.0 → 1.08`; videos muted, from their start, wrapped in `<Loop>` when shorter than the overlay.
- **Agent code boundary (row 11):** motion-graphic `code` is plain JS + JSX (no TypeScript, no `import`/`export`), ≤ `MAX_MG_CODE = 20_000` chars; the server transpiles it with `typescript` (`jsx: React`, `target: ES2020`), rejects a denylist of identifiers (`window document globalThis self fetch XMLHttpRequest WebSocket eval Function require process localStorage sessionStorage indexedDB navigator setTimeout setInterval setImmediate queueMicrotask Worker importScripts postMessage location`), dynamic `import()`, `with`, and code without a top-level `const Component`; stores `compiled` (≤ 60 000 chars) next to `code`. The server **never executes** it: `compiled` runs only inside Chrome (Remotion render, `GET /frame`, browser `Player`) through `new Function` with an explicit scope `{ React, AbsoluteFill, Img, Easing, interpolate, interpolateColors, random, spring, useCurrentFrame, useVideoConfig }` and inside an error boundary that draws `⚠ <mgId>` instead of failing the render. `<Img>` sources come only from `image` props (asset ids → URLs) and `item.brand.logoUrl`.
- **Brand kit (row 12):** `palette` hex `#RRGGBB` (`primary`, `accent`, `text`, `background`), `fontFamily` matching `/^[A-Za-z0-9 -]{1,60}$/` used verbatim as the CSS family with `system-ui, sans-serif` fallback (render and preview both run on this Mac, so an installed font is consistent; Google-font loading is plan 4), `logoAssetId` (an image asset or `null`), `grade` `0..1` (default `0.4`; `0` = no grade). `brand: null` = template colours, no grade. Captions under a brand: `text` → caption text, `accent` → active word and `keyword` emphasis, `primary` → `noun` and `pictorial` emphasis; the template's `background` box and `weight` stay.
- **One write path:** overlays, motion graphics and brand change only through `POST /api/projects/:id/actions` (web panel and MCP alike, guarded by `baseVersion`). The only other writes are the B-roll job (`POST …/broll`) and `PATCH /api/projects/:id {mediaSource}` (web) / `setMediaSource` (action). Every new action except `setMediaSource` sets `rerender: true`; `setShotKind` sets it when the project has overlays (their visibility follows the shot kind).
- **Remote media is untrusted:** `importRemote` uses the injected `deps.fetch`, accepts `https:` only (request URL and final response URL), caps bodies at `50 MiB` (declared and streamed), checks `content-type` ∈ {`image/jpeg`, `image/png`, `image/webp`} for images / {`video/mp4`} for video, probes with `Media.probe` (ffprobe whitelist from plan 1, extended with `image2,png_pipe,jpeg_pipe,webp_pipe`) and removes the file on any failure (`bad_remote_media`). Stock video results longer than `30 s` or wider than `1920` px are skipped.
- **Uploads** gain images: `UPLOAD_LIMITS.mimeTypes` += `image/png`, `image/jpeg`, `image/webp` (same 2 GiB cap, same probe).
- Durations, cuts, rendering as plan 2: source time stored, `mapTime` for output time, one `captionVideoProps()` for preview, frames and export. Single wire contract in `shared/contract.ts`; `shared/types.ts` only re-exports. `database/schema/schema.sql` changes are `ADD COLUMN IF NOT EXISTS` (unapplied until `make db && npm run dev:server`; Docker is not running — PROJECT.md says so). The Pg `COL` map is typed over `keyof Project`, so typecheck enforces every new field.
- Mobile-first: controls ≥ 44 px, one column under 768 px. TDD, colocated tests, `npm run verify` green after every task; backend imports relative; commits carry no AI co-author lines (`.githooks/commit-msg` strips them). Review subagents: one whole-branch review at the end (owner's rule), not per task.

## Review Focus

1. **Overlay whose shot was re-planned** (`run_job plan` renumbers shots, or the user flips a shot to `Talking Head`): it is not drawn, inspect/panel call it `stale`, and the next `run_job broll` replaces it. → Task 6 test `overlays of unknown or non-b-roll shots are not drawn`; Task 8 test `a re-plan hides overlays until the next b-roll run`.
2. **Motion graphic that throws** (reads a prop it never declared, bad JSX at runtime): the frame and the MP4 still render, with a `⚠ mg-<n>` placeholder where the MG would be, so the agent sees it in `render_frame`. → Task 7 test `an evaluation error yields the broken placeholder component`; gated test `renders a motion graphic that throws without failing`.
3. **Motion graphic that never returns** (`while (true)`): Remotion's per-frame timeout (30 s) fails the render / `GET /frame` instead of hanging the API; `wait_job` reports `FAILED` with the error. → Task 7 gated test `an infinite loop fails the render within the timeout`.
4. **Agent and web tab editing the same project**: the web panel's action lands on a stale `baseVersion` → `409 stale` → it refetches and says "Project changed elsewhere — reloaded, try again"; nothing is lost. → Task 10 test `a stale action refetches and explains`.
5. **Logo or MG image prop pointing at a video or a missing asset**: `400 bad_asset`, whole batch rejected. → Task 5 test `image props and logos must be image assets`.
6. **Beat inside an enabled cut**: clipped to the kept part (dropped under 500 ms), back when the cut is un-ticked. → Task 6 test `overlays follow enabled cuts`.
7. **Landscape stock in a 9:16 project / no stock hit / fal failure / no B-roll shots**: orientation in the query, `intent` retry then `broll_not_found:<beatId>`, Pexels fallback, `no_broll_shots` warning — the job always ends `ready` or `failed`, never stuck in `generating`. → Task 3 test `pexels query carries orientation`; Task 8 tests `empty stock result skips the beat`, `generation failure falls back to stock`, `no b-roll shots completes with a warning`.
