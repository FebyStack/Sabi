# Locked Spec (confirmed 2026-10-18)

Changes to this list go here first, then into code — never absorbed silently.

| # | Decision | Locked value |
|---|---|---|
| 1 | Platforms | **Desktop + mobile web editing.** Full timeline editing must work on phones (touch drag/pinch), not just upload/review. Overrides §10.6 desktop-first. |
| 2 | Privacy | Uploads, proxies, generated media and renders auto-delete **30 days** after last access; cookie/analytics **consent banner** (decline = no analytics); EXIF stripped on upload; no third-party session replay. |
| 3 | Roles | **Solo users only** for MVP: one account = one workspace, no sharing/orgs. Schema keeps `orgId` nullable so orgs can be added later. |
| 4 | Outputs | **MP4 (HD 1080p + 4K) with burned-in captions and overlays, plus SRT and VTT sidecars.** No alpha overlay export, no project JSON export in MVP. |
| 5 | States | **First-run demo project** (pre-rendered sample with captions + B-roll) + **staged progress** (uploading → transcribing → planning → generating → rendering, with %), empty-state CTAs on Projects/Timeline/B-roll panels; no coach-mark tour. |
| 6 | Integration | **Standalone new project** in Febriel's hybrid architecture (React+Vite / Node+Express / Postgres / Docker), own S3-compatible storage (MinIO dev, R2/S3 prod). No Supabase, no existing site. |
| 7 | Providers | **Self-hosted ASR + LLM on Febriel's Apple-Silicon Mac**: `whisperX` (word timestamps + alignment, multi-language) and `Ollama` (planner, emphasis tagging, translation, chat agent). **No Anthropic API.** Generation is **hybrid**: `fal.ai` for images (Flux) and video clips (Kling/Hailuo) as the default, **Pexels stock** always available; each project has a user-facing **Media source** setting: `Generate (fal.ai)` or `Stock only`. |
| 8 | Coverage | All four: (a) English captions with word-level karaoke, AI emphasis (nouns/keywords/pictorial), auto emoji; (b) multi-language transcription + translated subtitle tracks; (c) filler/pause recommended cuts + typed shots `Hook / B-Roll / Talking Head / Talking Head & B-Roll`; (d) generated image **and** video B-roll + chat-to-edit agent (tool loop: inspect → generate → apply_actions → render_frame verify). |
| 9 | Monetization | Not decided; MVP has **no billing** — a per-user credit ledger is logged (fal.ai cost per generation) so a credit model can be switched on later. |
| 10 | Editing agent (added 2026-10-20) | **Claude is the main editing AI, on Febriel's Claude subscription only — never the Anthropic API.** Sabi exposes an **MCP server** (`backend/mcp`, stdio, registered in `.mcp.json`) with the captions.ai-style tool loop — `inspect_project → apply_actions → render_frame (verify) → run_job` — and a Claude Code session in the desktop sidebar drives the edit while the web preview updates over SSE. Button-driven automation in the web app (Plan edit, translate, auto B-roll) stays on local Ollama (row 7); the web app never calls Claude itself. This is a personal-editing setup: Sabi's own end users cannot use Febriel's subscription. Row 8d's "chat-to-edit agent" is satisfied by this, not by an in-app chat. Plan 3 (B-roll overlays) is paused until the MCP server lands; overlay actions join the MCP action set when it resumes. |
| 11 | Motion-graphics B-roll (added 2026-10-20) | **The editing agent (Claude, row 10) authors motion-graphics B-roll as Remotion components** rendered inside Sabi's own `CaptionVideo` composition — one render pass, browser preview = export. Chosen over HyperFrames (HTML clips; no HyperFrames skill or dependency is added). Agent-written component code is a project asset, validated before it is accepted, and runs only in the Remotion render and the preview player. MG layers join plan 3b's overlay layer (beat placement, caption-aware placement); the agent gets an MG skill adapted from ChatCut's `create-motion-graphics` craft rules (visual-language alignment, one representative MG before a batch, verify with `render_frame`). Ships with resumed plan 3b. |
| 12 | Brand look (added 2026-10-20) | **Per-project brand kit** — palette (primary / accent / text / background), font, optional logo — drives caption colours and emphasis colours, motion graphics, **and a footage colour grade** (a brand-toned look on the camera video, applied in the composition so preview = export). Settable by the agent via MCP actions; ships with resumed plan 3b. |
| 13 | Tagalog (added 2026-10-20) | **Full pipeline, not just the agent:** Tagalog (`tl`) and Taglish clips transcribe with word timings (the locked whisperX 3.8.6 already ships a `tl` aligner; the real gaps are words silently dropped when a segment fails to align, a language with no aligner failing the whole job, and Taglish auto-detected as `en` with no way to choose the language), Tagalog/Taglish filler cuts (e.g. *ano, kasi, parang, 'yung, ganun, eh*), Tagalog-aware emphasis and caption line breaks, and Tagalog/Taglish editing guidance in the `sabi-editor` skill. Its own small plan after plan 3. |
| 14 | Editor UI (added 2026-10-21) | **One write path, explicit export.** Every web edit is a typed action batch on `POST …/actions` with `baseVersion` and `render: false`; the browser `Player` is the live preview, the MP4 is rendered only from an **Export** panel (1080p or 4K = Remotion `scale: 2`), and `outputs.stale` marks renders older than the last visual edit. The timeline is **touch-first, in source time** (enabled cuts shaded): drag/move overlays and motion graphics, drag shot boundaries (`setShotBounds`), drag caption phrase boundaries (`retimePhraseRange`, words scaled), tap cuts to toggle, tap words to set emphasis (`setWordEmphasis`) and emoji (`setPhraseEmoji`); pinch zoom; keyboard nudge. Agent edits (`apply_actions`) appear live over SSE without reload, with the changed layers highlighted; a `409 stale` is shown with **Retry on the new version**; undo is client-side inverse actions, cleared by any external edit. The web-only write routes (`PUT /phrases`, `PUT /template`, `PATCH /plan`, `PATCH /projects/:id`) are retired. |
| 15 | Fonts (added 2026-10-21) | **Bundled OFL set, no Google Fonts.** `BRAND_FONTS = Inter, Montserrat, Poppins, Bebas Neue, Playfair Display, Space Grotesk` from `@fontsource` packages, imported by the composition so the Player and the render browser load the same files; `brand.fontFamily` and the caption-style font are enums of these. Preview = export, offline, no third-party request. |
| 16 | Template customisation (added 2026-10-21) | **Per-project caption style over a preset**, not saved custom templates (solo user): `project.captionStyle` (`sizePx`, `y`, `uppercase`, `weight`, `background`, `animation`, `fontFamily`) applied on top of `captionTemplateId` and the brand kit; the Style panel also edits the brand kit (palette, font, logo, grade) and warns when caption text/background contrast < 3:1. |
| 17 | Demo project (added 2026-10-21) | **Committed bundle** `database/seed/demo/` (the 21 s `test-clip-9x16.mp4`, two attributed Pexels stills, `project.json` with captions + plan + overlays + brand, the pre-rendered MP4/SRT/VTT), seeded on boot when there are no projects; `project.demo: true` shows a badge; it is an ordinary, editable, deletable project (`DELETE /api/projects/:id` ships with it). |
| 18 | Consent, analytics, retention (added 2026-10-21) | Banner on first visit states the 30-day auto-delete and asks for anonymous usage analytics; the choice lives in `localStorage` (`sabi.consent`). Analytics is a no-op unless the viewer accepted **and** `VITE_POSTHOG_KEY` / `VITE_POSTHOG_HOST` are set (PostHog HTTP capture, no SDK, no cookies; events: funnel upload → captions → plan → B-roll → render → export). The **30-day retention sweep** (projects by `last_access`, files included) ships with this plan, not plan 5, so the banner's promise is enforced. |

Blueprint impacts: §10.2 Timeline must be touch-first (pointer events, 44 px targets, pinch-zoom); §10.3 steps 2/3 run as local workers (whisperX via Python sidecar, Ollama HTTP) with hosted fal.ai only in step 5; §10.12 adds a `worker-ai` container profile that targets the Mac host (Metal) in dev and a GPU VPS in prod; §10.3 step 8 (agent) is in MVP scope.
